# MODEL FORGE — прототип дизайна

Интерактивный frontend-прототип интерфейса платформы MODEL FORGE для запуска и мониторинга обучения ML-моделей.

**В проекте:** главная страница, проекты, датасеты, создание запуска, список запусков, мониторинг обучения и просмотр результатов.

**Запуск:** откройте `model_forge_best_case/model_forge_web/index.html` в современном браузере. Установка зависимостей и сборка не требуются.

**Важно:** это демонстрационный прототип интерфейса. Данные и метрики условные; серверная часть, настоящее обучение моделей и сохранение данных не подключены.
